ATE WEB — sitio estático gratuito

Archivos:
- index.html: página principal.

Cómo publicarlo gratis:
1. Abrí GitHub y creá una cuenta si no tenés.
2. Creá un repositorio nuevo, por ejemplo: ate-lobos-roque-perez-saladillo.
3. Subí index.html.
4. En Settings > Pages elegí publicar desde la rama principal (main).
5. GitHub te dará una dirección pública para compartir.

Para cambiar noticias, fotos o textos, editá index.html.
